Executive summary

十条结论：记忆的问题不是"要不要"，而是"记什么、何时写、写到哪、存多少"

  1. 标准 VLA 是马尔可夫的，而操作任务不是：掀盖看一眼、读一张数字卡、看别人点一遍顺序——证据出现后就消失。
  2. 前沿从"存多少"转到了"何时写"：EventVLA / KEMO / UniMem / WeaveLA / MemoryWAM 在 2026 年 6–8 月从不同架构同时转向事件驱动的稀疏写入。
  3. 历史大多是当前帧的冗余副本（Present but Not Remembered 的探针审计）；记忆增强应注入只属于过去的信息。
  4. 原图还是 latent 取决于要恢复多少比特：EventVLA 的 24.9 vs 75.2 与 TRACE 的 69.23 并不矛盾。
  5. 寻址被低估：TRACE 用轨迹签名让写入时刻与读取时刻有稳定对应，倒放历史路由相似度掉到 37.8。
  1. 可靠性来自有纪律的状态更新，不是容量：AGM 验证后推进、EventVLA NMS + 冷却、TRACE 门控写入是同一原则。
  2. 计数与过程记忆上双系统仍领先：RoboMME / RoboMemArena 榜首都是高层管状态的方案。
  3. 记忆的成本趋近于零：NativeMEM 每帧 1 token、TempoFit 免训练、StreamPI 零参数；EventVLA 的 3× 延迟是短板。
  4. 多机器人是同一问题的另一张脸：搭档相位是从历史推断的隐变量（SAI），但还没有人给它显式记忆。
  5. 评测在分裂、诊断在成熟：一年 12 套基准；并排任何两个数字之前先查口径账本。

EventVLA §1–2 的诊断

为什么帧堆叠收益不稳定：历史 ≈ 当前帧的副本

Liao & Cao 对 Octo-Small / Octo-Base / CronusVLA-0.5B 做逐层线性探针 + 因果交换干预：过去帧内容全网络可解码（A₁ 0.39 / 0.36 / 0.14），但只属于历史的信息几乎为零（A₄ +0.019 / +0.015 / −0.011）；历史只在当前帧被全黑遮挡时才被因果使用，且能否用注入的历史驾驭动作因架构而异（Octo 不能，CronusVLA +0.167）。

设计准则：注入过去独有的信息，而不是更多的历史——这正是稀疏事件帧、签名增量、动作历史压缩在做的事。

EventVLA · mechanism

EventVLA：把"何时该记住"变成一个可学习的预测问题

记忆 Mt = At ∪ Et

  • 锚帧 At = {o₀} ∪ {ot−30, ot−15}：全局布局 + 运动线索（规则）
  • 事件帧 Et：KEM 写入，Nmax = 5，FIFO
  • concat([At, Et−1, ot]) 直接进 VLM 视觉编码器——"读"就是多帧注意力

p̂t = σ(MLP(ht)) ∈ [0,1]H, H = 50 ； p̂ti ≥ 0.55 ⇒ 存 ot+i

1-D NMS（w = 8）+ 冷却（C = 10）防止同一事件灌满缓冲区

训练与"为什么按整块预测"

  • 标签：Qwen3-VL-235B 离线看演示输出关键帧步（仿真误差 < 10 步，真机 < 50 步）
  • 软标签：升余弦核 y = ½(1 + cos π|t+i−t*|/R)；L = Laction + 0.1·Lkem
  • 师生课程：真值缓冲 → 自身预测，α: 1 → 0

事件常在一个动作块中途出现又消失，逐步分类器来不及；共享 ht 让 KEM 知道策略接下来要做什么，能预约一次写入。

TRACE · mechanism

TRACE：内容与地址分离——当前画面决定"记什么"，走过的路决定"存到哪、从哪取"

延迟证据 → 轨迹签名做钥匙

  • 短窗口下 xt−w+1:t ≈ x′t−w+1:t 但 a*t(Ht) ≠ a*t(H′t)：单帧策略注定至少错一半
  • 内容 et = φx(xt)：多视角视觉 + 本体感受
  • 地址：17 维状态路径的深度-3 路径签名，17 + 17² + 17³ = 5219 维，加增量 δt
  • 对时间重参数化、常数偏移不变，对顺序敏感；流式 0.52 ms

ωt,k = softmaxk(⟨WQρt, WKm̄t−1,k⟩/τ√d) ； mt,k = (1−β) mt−1,k + β m̃t,k

适配器只做翻译，骨干、动作头、损失都不改

  • ACT：槽 → 512 维记忆 token 拼进注意力 memory（+0.79 M）
  • Diffusion：池化 → 零初始化 MLP → 加性全局条件（+16.03 M）
  • 共享更新器 11.91 M；K = 4 / 6 槽 × 512 维
  • 三个稳定器只作用于记忆：Lbal 防槽塌缩 · Lent 防弥散写入 · Lcons 防读写失配（去掉：69.23 → 66.10）

训练与部署走同一条因果扫描：不用线索标签、分支标签、未来帧，也不做测试时演示检索。

SAI · curriculum

SAI：搭档看不全，历史和课程都要替它补——协调是搭档分布的函数，不是架构的函数

单遥操作者三阶段

  1. A 与顺从的人类搭档学任务；搭档区域随机化（噪声 / 模糊 / SD 修补）防止学人类外观捷径

Routes

同一个目标，五条路线：记忆可以被触发、被压缩、被寻址、被符号化、被预测

1 · 事件 / 关键帧（5）

只在"发生了什么"时写，存原图或 token。EventVLA（学习触发）、KEMO（运动学 + 视觉规则）、UniMem（事件分类器）、WeaveLA（子目标完成）。

2 · 稠密压缩历史（25）

每帧都进，靠压缩 / token 化 / KV 复用控制成本。MemoryVLA、HAMLET、NativeMEM（1 token/帧）、TempoFit（免训练）、StreamPI（零参数）、DySta。

3 · latent / 循环 / 槽（20）

历史压成固定向量或槽递归更新。TRACE（签名寻址）、μVLA（最小循环）、Chronos（SSM 状态）、TFP（进度信念）、GMP（何时回忆）。

4 · 双系统 / 符号（19）

高层维护文本 / 图 / 进度指针，低层执行。MEM、MemER、AGM（验证后推进）、HyMeS（记忆在代码）、PonderPounce、BATON。

5 · 世界模型内的记忆（3）

记忆服务于预测，预测服务于动作。MemoryWAM（近期 + 事件锚帧 + gist）、MemoryVAM、TriVLA。

第六个方向 · 多机器人搭档记忆（9）

搭档相位是只能从历史推断的隐变量。SAI、HATS、Duet、Tri-Manual、AutoIntervene——几乎都在解数据采集，没有显式记忆模块。

Method lessons

三篇论文教给我们的三件事：单变量对照、报告代价、用诊断代替猜测

把一个默认做法拆开单独测

EventVLA 只换记忆表征（原图 vs latent：75.2 vs 24.9）；TRACE 只换寻址（有无签名路由：69.23 vs 52.17）；SAI 只换数据课程（架构固定：独立 vs 搭档条件 vs SAI）。说服力来自单变量对照。

报告代价
